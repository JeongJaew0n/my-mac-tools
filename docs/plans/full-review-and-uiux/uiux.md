# uiux — UI·UX 개선 (2026-11-06)

조사: Apple HIG(The menu bar · Accessibility · Context menus)와 비슷한 앱(Amphetamine, KeepingYouAwake,
Stats, IP 모니터류)을 기준으로 12개 안을 뽑고, **새 Tool·새 폴링 없이 기존 화면을 다듬는 것** 중
값 대비 위험이 좋은 것부터 구현했다.

> 조사에서 나온 의견이라 리뷰와 같이 취급해 커밋하지 않았다. 읽고 판단해 주세요.

## 구현한 것

| # | 무엇 | 왜 | 확인 |
|---|---|---|---|
| 1 | 덮어도 작업 · 화면 가리기 · 속도 측정의 시작 버튼을 `PrimaryButtonStyle` 로 | 잠자기 방지만 강조색 버튼이고 나머지 셋은 회색 기본 버튼이었다. 속도 측정의 시스템 기본 버튼은 다크에서 강조색 위 흰 글자(대비 1.98, DESIGN.md §4) | 렌더링 캡처(ko 라이트, ja 다크 320pt). 덮개 버튼엔 Return 을 붙이지 않음(§8.5 판단 유지) |
| 2 | 탭 버튼에 VoiceOver 이름·"실행 중" 값·선택 상태 | 아이콘만 그릴 때 VoiceOver 가 기호 이름("cup and saucer")을 읽고, 실행 중은 색으로만 보였다(HIG Accessibility) | 코드. 새 키 `a11y.running` |
| 3 | 보기 메뉴에 보이는 탭마다 항목과 ⌘1… | HIG The menu bar: 탭형 앱은 보기 메뉴에 탭과 단축키를. 탭을 바꾸려면 마우스가 필요했다 | 설치본: 보기 메뉴에 ⌘1~⌘6(숨긴 화면 가리기는 빠짐), 메뉴로 탭 전환 → `selectedTab` 바뀜, 창 수 1 그대로(실측) |
| 4 | 상태 줄을 `statusLine(isOn:_:)` 하나로, VoiceOver 한 문장 | 같은 점+문장을 네 곳이 간격을 달리해 그렸다 | 렌더링 캡처 |
| 5 | 메뉴바 아이콘에 툴팁·접근성 값(무엇이 돌고 있는지), 메뉴에 "설정 열기…" | 5pt 초록 점 하나뿐이었다. 설정으로 가는 길이 앱 메뉴뿐이었다 | 설치본: 툴팁 "MyMacTools / 잠자기 방지 — 시간 제한 없음", 메뉴에 "설정 열기…"(실측) |
| 5′ | "창 열기" 가 창이 있으면 그 창을 앞으로 | `WindowGroup` 의 `openWindow` 는 부를 때마다 창을 더 만든다 — 메뉴의 "창 열기" 가 그대로 불렀다 | 설치본: 눌러도 창 1개(실측). 수정 전 코드로 두 개가 되는지는 재현하지 않았다 |
| 6 | 주소 복사를 VoiceOver 로 알림 | 1.5초 뒤 사라지는 글자뿐이었다(HIG: 시간 제한 있는 표시 최소화) | 코드 |
| 8 | "색상 없이 구별" 설정이 켜지면 실행 중 탭 아이콘에 점 | 초록/회색 색차뿐이었다(HIG Accessibility) | 코드 |
| 9 | 로컬호스트: 걸러서 0개면 "필터 지우기", 검색창 Esc 로 지우기 | 되돌리려면 범주 메뉴와 검색창을 각각 찾아야 했다 | 코드. 새 키 `localhost.clearFilter` |
| 11 | 속도 측정이 끝나거나 실패하면 VoiceOver 로 알림(취소는 알리지 않음) | 약 21초 걸리는 작업의 끝이 화면 변화뿐이었다 | 코드 |
| — | 포트·pid 를 쉼표 없이 | 렌더링하다 발견. `Text("\(정수)")` 가 현지화 키로 읽혀 "5,000"·"pid 50,780" 으로 나왔다 | 렌더링 캡처(수정 전·후) |

## 하지 않은 것

| # | 안 | 이유 |

| 10 | 화면 가리기 사진 끌어다 놓기·썸네일 | 썸네일 크기 토큰을 새로 정해야 하고 큰 이미지 디코딩 비용 |

## 테스트 방법

실제 창은 사용자의 '화면 끔 유지' 세션 때문에 캡처할 수 없어, 앱 소스(진입점 제외)와 작은 main 으로
`ContentView` 를 화면 밖 창에 그려 PNG 로 찍었다(별도 bundle id 라 설정이 섞이지 않는다).
메뉴는 설치본을 System Events 로 읽고 눌렀다.
