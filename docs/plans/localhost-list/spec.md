# spec — localhost-list

## 목표

내 맥에서 **듣고 있는 localhost 포트**를 네 번째 Tool 로 보여준다. 무엇이 그 포트를
잡고 있는지 알려주고, 브라우저로 열고, 필요하면 프로세스를 끈다.

조사 결과와 실측 근거는 `research.md`.

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 배치 | **새 Tool. 네 번째 탭** | 사용자 지시. 포트는 잠자기·덮개·가리기와 무관해서 기존 Tool 에 얹을 자리가 없다 |
| 조회 방식 | `sysctl(KERN_PROC_ALL)` + `proc_pidinfo(PROC_PIDLISTFDS)` + `proc_pidfdinfo(PROC_PIDFDSOCKETINFO)` | 실측 — `lsof` 와 결과가 정확히 일치하고 전수 조회가 5ms 미만이다. 프로세스를 띄우지 않는다 |
| localhost 의 정의 | `127.0.0.1` · `::1` 과 함께 **`0.0.0.0` · `::` 도 넣는다.** 모든 인터페이스에 바인드한 것은 localhost 로도 닿는다 | 실측한 20개 중 4개가 `0.0.0.0`/`::` 였다. 빼면 `ControlCenter:5000` 처럼 실제로 localhost 로 열리는 포트가 사라진다 |
| UDP | **제외한다. TCP LISTEN 만** | UDP 에는 LISTEN 상태가 없어 "듣고 있다" 를 같은 기준으로 판정할 수 없다. 기준이 다른 것을 한 목록에 섞지 않는다 |
| IPv4/IPv6 중복 | 같은 `(pid, 포트)` 는 **한 줄로 합치고** 주소군을 칩으로 함께 보여준다 | `ControlCenter:7000` 이 IPv4·IPv6 두 줄로 나온다. 같은 서버가 둘로 보이면 세는 것이 틀린다 |
| 브라우저로 열기 | 항상 제공한다. `http://localhost:<포트>` 로 `NSWorkspace.open` | 아래 참고 |
| HTTP 인지 판별 | **하지 않는다.** 앱이 내 서버에 요청을 보내지 않는다 | 판별하려면 실제로 요청을 보내야 한다. 남의 개발 서버에 앱이 말을 거는 것은 이 앱이 할 일이 아니다. HTTP 가 아니면 브라우저가 알아서 실패하고, 그 비용이 요청을 몰래 보내는 것보다 싸다 |
| 프로세스 종료 | 우클릭 → `중지하기`. `SIGTERM` | 카페인 목록과 같은 패턴이다. 같은 uid 만 보이므로 권한도 같다 |
| 갱신 | 창이 보이는 동안, 2초 간격 | 카페인 목록과 같은 규칙. 5ms 라 더 짧게도 되지만 규칙이 둘이 되는 것보다 낫다 |
| 보이는 범위 | 내 uid 소유만 (`PROC_PIDLISTFDS` 의 제약) | root 데몬의 포트는 안 보인다. 개발 서버는 전부 내 uid 라 목적에는 맞는다. 화면에 이 사실을 한 줄로 알린다 |
| 이름 해석 | `CaffeinateScanner.friendlyName` 을 **공용으로 빼서** 쓴다 | 같은 문제다. `proc_pidpath` 가 실패하는 프로세스가 있고(실측 — pid 11100), 짧은 이름은 16자로 잘린다 |

## 화면 모양

```
 ▸ 잠자기 방지 · 덮어도 작업 · 화면 가리기 · 로컬호스트     ← 탭 4개
 ─────────────────────────────────────────
 ● 8개 듣고 있음
 내 계정이 띄운 것만 보입니다

 ┌───────────────────────────────────────┐
 │ 8501                          [열기]  │
 │ python3.12 (pid 13012)                │
 │ [127.0.0.1] [IPv4]                    │
 ├───────────────────────────────────────┤
 │ 7000                          [열기]  │
 │ ControlCenter (pid 758)               │
 │ [0.0.0.0] [IPv4] [IPv6]               │
 └───────────────────────────────────────┘
```

포트를 가장 크게 둔다. 이 화면을 여는 이유가 "몇 번이 잡혀 있나" 이기 때문이다.
줄 우클릭 → `중지하기`. 비었으면 "듣고 있는 것이 없습니다" 한 줄만 둔다.

포트 오름차순으로 정렬한다. 시작 시각 순서는 이 목록에서 쓸 데가 없다.

## 완료 조건

- 네 번째 탭이 뜨고, 탭 이름 옆 점은 **듣고 있는 것이 하나라도 있으면** 초록이다
- 목록이 `lsof -iTCP -sTCP:LISTEN -P -n` 의 내 uid 결과와 일치한다
- `열기` 가 기본 브라우저로 `http://localhost:<포트>` 를 연다
- 우클릭 `중지하기` 가 그 프로세스를 끄고 목록에서 사라진다
- 창을 닫으면 폴링이 멈춘다
- 문구가 ko · en · ja 세 언어로 나온다

## 범위에서 빼는 것

- **UDP · UNIX 도메인 소켓** — 위 결정 참고
- **연결 수 표시** — TCP 95개 중 LISTEN 20개라 연결된 소켓을 세어 붙일 수 있지만,
  이번 요청은 "무엇이 듣고 있나" 다. 나중에 원하면 얹는다
- **root 포트** — 볼 방법이 권한 상승뿐이다. 이 앱은 `pmset` 에만 권한을 쓴다
