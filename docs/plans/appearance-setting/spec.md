# spec — appearance-setting

## 목표
설정 창에서 앱의 모양을 **시스템 설정 / 라이트 / 다크** 중에 고른다. 시스템은 그대로 두고
이 앱만 고정할 수 있게 한다.

## 원 요청 (2026-09-28)

> 우리 앱 설정에 넣어주. 기능 구현

(앞 대화: "라이트모드랑 다크모드는 어케바꾸는데?" → 지금은 시스템을 따르기만 한다고 답함)

## 결정

| 축 | 결정 | 근거 |
|---|---|---|
| 적용 수단 | `NSApp.appearance` — 시스템 = `nil`, 라이트 = `.aqua`, 다크 = `.darkAqua` | 앱의 모든 창(본 창·설정 창·화면 가리기)에 한 번에 먹는다. 색 토큰은 그리는 순간의 appearance 를 따르므로 따로 할 일이 없다 |
| 저장 | `UserDefaults` `appearance` (`system`/`light`/`dark`) | 다른 설정과 같은 자리 |
| 적용 시점 | 앱이 설정을 읽는 순간 + 바꾸는 즉시 | 재시작이 필요 없어야 한다 |
| 자리 | 설정 창 맨 위, 탭 목록보다 앞 | 창 전체에 걸리는 설정이라 먼저 보인다 |
| 조작 | 세 칸짜리 segmented | 선택지가 셋뿐이고 배타적이다 |

## 범위 밖

- **메뉴바 아이콘** — 메뉴바는 앱이 아니라 시스템 메뉴바의 모양을 따른다. template 이미지라 바뀌지 않는다
- API 로 모양 바꾸기
