## 시험하는 것
- 현지화: `L10n.Key` 전부가 ko/en/ja 에 있고, 세 언어의 키 묶음과 형식 지정자(`%@`·`%d`)가 같다
- 기본값: 옛 저장값(항목이 빠진 것)도 읽힌다, 저장·읽기 왕복
- 단축키: 표시 순서, Carbon 수정자, 같은 조합 판별, 수정자 없는 키 거절
- caffeinate 인자 해석, IntelliJ 테마 생성(남은 자리표시자 없음·JSON 으로 읽힘), IP 꼴 판별
- API: 응답 꼴, 모르는 메서드, 잘못된 요청, `sleep.start` 의 형 검사(거절되면 값이 그대로), 사람이 해야 하는 메서드(`needsHuman`),
  끄기·열기의 대상 검사(`badParams`·`notFound` — 쓰이지 않는 pid·포트만), 사진 없는 `cover.start`, 읽기 메서드
- 상태 전이(세션 없이): 기본값 저장·되돌리기·다음 실행, 망가진 저장값, 덮개 규칙, 탭 숨기기(전부 숨긴 값 거부·모르는 이름·마지막 하나),
  화면 가리기의 덮지 않는 경로(읽을 수 없는 사진, 사진 없이 시작)
- 저장 형식: 단축키·덮개 기본값 JSON, 탭·화면 모드 raw 값
- 조립 키: IntelliJ 색 역할마다 `intellij.role.*` 가 있다(빠지면 탭 이름이 대신 나온다), 열거형 이름 키
- 토큰 생성기: 생성물이 최신, 참조가 층을 건너 풀린다, 순환·없는 참조·숫자 아님·틀린 색·모르는 시스템 색·알파 범위·시스템 색에 알파는 멈춘다, 테마는 값만 바꾼다

## 시험하지 않는 것
| 것 | 이유 |
|---|---|
| 세션 시작·화면 끄기·음소거 실제 동작 | 사용자의 화면과 소리를 바꾼다. 필요할 때 일회용 프로그램으로 확인했다 |
| 사진이 있는 화면 가리기 | 모든 화면을 실제로 덮는다 |

`UserDefaults` 를 쓰는 시험은 시험 프로세스의 도메인을 쓴다 — 앱(`com.jjw.mymactools`) 설정은 바뀌지 않는다(시험 전후 `defaults export` 비교로 확인). 같은 키를 쓰는 시험은 모두 `@MainActor` 이고 기다림이 없어 서로 끼어들지 않는다.
| 덮개(`pmset disablesleep`) | 관리자 권한 |
| 진짜 키 입력 | 합성 키로는 Carbon 핫키가 발동하지 않는다 |
