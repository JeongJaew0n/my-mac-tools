# spec — settings-window

## 목표

macOS 표준 자리(`MyMacTools > 설정…`, `⌘,`)에 설정 창을 만든다. 첫 화면에서 **어떤
Tool 이 탭으로 보일지** 켜고 끈다.

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 창을 만드는 법 | SwiftUI `Settings` 씬 | 앱 메뉴의 `설정…` 항목과 `⌘,` 단축키가 자동으로 붙는다. 직접 `NSWindow` 를 띄우면 그 두 가지를 손으로 만들어야 하고 macOS 관례와 어긋난다 |
| 저장 자리 | `UserDefaults` 의 `hiddenTabs` — **숨긴 것**의 목록 | 보이는 것을 저장하면 **나중에 Tool 을 추가했을 때 기본으로 숨겨진다.** 숨긴 것만 저장하면 새 Tool 은 자동으로 보인다 |
| 최소 한 개 | **마지막 하나는 끌 수 없다.** 그 토글을 비활성한다 | 탭이 0개인 창은 빈 화면이다. 끄고 나서 되돌릴 방법이 설정 창뿐인데, 그 창을 여는 법을 모르면 갇힌다 |
| 보던 탭이 숨겨지면 | 남아 있는 **첫 번째 탭**으로 옮긴다 | 선택은 `@AppStorage("selectedTab")` 에 남아 있어, 숨긴 탭을 가리키면 본문이 비어버린다 |
| 메뉴바 | **영향받지 않는다.** 숨긴 Tool 도 메뉴바에서 켜고 끌 수 있다 | 요청은 "**기본 탭**에 표시될 것"을 고르는 것이다. 탭에서 치웠다고 그 기능을 못 쓰게 만드는 것은 다른 이야기이고, 창을 닫고 메뉴바로 쓰는 흐름을 깨뜨린다 |
| 설정 항목 이름 | 탭 이름을 그대로 쓴다 (`L10n` 의 `tab.*`) | 설정에서 고른 것과 화면에 보이는 것이 같은 말이어야 한다 |
| 창 크기 | 고정. 내용에 맞춘다 | 설정 창은 목록 하나뿐이다 |

## 화면

```
┌─ 설정 ───────────────────────────────┐
│                                       │
│  탭에 표시할 기능                      │
│                                       │
│    잠자기 방지            [ ●——]      │
│    덮어도 작업            [ ●——]      │
│    화면 가리기            [——○ ]      │
│    로컬호스트             [ ●——]      │
│                                       │
│  숨긴 기능도 메뉴바에서는 그대로        │
│  쓸 수 있습니다.                       │
└───────────────────────────────────────┘
```

마지막 하나만 켜져 있으면 그 토글은 흐려지고, 왜 못 끄는지 한 줄로 알린다.

## 완료 조건

- 앱 메뉴에 `설정…` 이 있고 `⌘,` 로 열린다
- 토글을 끄면 그 탭이 **즉시** 사라진다. 앱을 다시 켜도 유지된다
- 보고 있던 탭을 끄면 남은 탭으로 옮겨가고 본문이 비지 않는다
- 마지막 하나는 끌 수 없다
- 숨긴 Tool 도 메뉴바에서 켜고 끌 수 있다
- 나중에 Tool 을 추가하면 **설정을 건드리지 않아도 보인다**
- 문구가 ko · en · ja 세 언어로 나온다

## 범위에서 빼는 것

- **탭 순서 바꾸기** — 요청은 표시 여부다. 순서는 `Tab.allCases` 를 따른다
- **메뉴바 항목 고르기** — 위 결정 참고
- 그 밖의 설정(간격·언어 등) — 언어는 이미 메뉴바에 있다
