# spec — menu-bar-item

## 목표
맥북 상단 상태 막대에 MyMacTools 아이콘을 띄운다. 창을 열지 않고도 **무엇이 돌고 있는지
보이고**, 기능을 켜고 끌 수 있게 한다.

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| Dock 아이콘 | **유지한다.** 메뉴바는 추가 | 기존 동작을 하나도 바꾸지 않아 되돌리기 쉽다 |
| 구현 | SwiftUI `MenuBarExtra` | 배포 타깃이 macOS 14 라 쓸 수 있는 것을 확인했다. `NSStatusItem` 을 직접 다루는 것보다 상태 연동이 단순하다 |
| 클릭 동작 | 드롭다운 메뉴 (`.menuBarExtraStyle(.menu)`) | 메뉴바 앱의 관례이고 가장 가볍다 |
| 메뉴 구성 | 기능 3개 토글 + `창 열기` + `종료` | |
| 상태 표시 | 하나라도 돌고 있으면 **아이콘이 채워진 모양**으로 | 덮개 기능은 앱을 꺼도 시스템에 남는다. 켜둔 것을 잊지 않게 하는 값어치가 크다 |
| 권한 | 없음 | `NSStatusItem` 생성에 권한이 필요 없는 것을 확인했다 |

## 메뉴 모양

```
┌─────────────────────────┐
│ ✓ 잠자기 방지            │
│   덮어도 작업            │
│ ✓ 화면 가리기            │
├─────────────────────────┤
│ 창 열기                  │
│ 종료                     │
└─────────────────────────┘
```

기능 항목은 `Toggle` 로 그린다. 색 점(`Circle().fill(.green)`)을 쓰지 않는 이유는 메뉴가
이미지를 template 으로 렌더링해 **녹색이 회색으로 죽을 수 있기** 때문이다. 탭바를 만들 때
같은 이유로 기성 스타일을 피했다(`docs/plans/tabbed-window/spec.md`). 메뉴에서는 체크마크가
관례이기도 하다.

## 바뀌는 기존 동작 — 창을 닫아도 세션이 안 끊긴다

지금은 창을 닫으면 `onDisappear` 에서 `BlackWorkManager.stop()` 이 돌아 **잠자기 방지가
꺼진다.** 메뉴바에서 켜고 창을 닫으면 그대로 꺼져버리므로 이 규칙은 더 이상 맞지 않는다.

창 닫기는 세션을 끊지 않게 바꾼다. 세션을 끝내는 것은 **정지 또는 앱 종료**다. 종료할 때
덮개 기능 경고가 뜨는 흐름은 그대로다.

## 중복 규칙 한곳으로

덮개 기능을 켤 때 "끝나면 Mac잠자기 모드" 를 함께 내려야 한다. `disablesleep=1` 이면
`pmset sleepnow` 가 거부되기 때문이다
(`docs/troubleshootings/reusable/pmset-sleepnow-refused-when-disablesleep-is-1.md`).

지금은 이 규칙이 `ContentView` 에만 있다. 메뉴에서도 켤 수 있게 되므로 **두 곳이 되기 전에**
한곳으로 모은다. 상태를 세우는 곳과 내리는 곳이 갈라져서 난 버그가 이미 두 번 있었다.

## 범위 밖

- 메뉴바 전용 앱으로 전환(`LSUIElement`)
- 메뉴에서 유지 시간·사진 같은 설정 변경 — 창에서 한다
- 남은 시간 표시

## 완료 조건

- [ ] 상태 막대에 아이콘이 뜬다
- [ ] 기능 3개를 메뉴에서 켜고 끌 수 있다
- [ ] 돌고 있는 기능에 체크가 보인다
- [ ] 하나라도 돌면 아이콘 모양이 바뀐다
- [ ] `창 열기` 로 닫았던 창이 다시 열린다
- [ ] `종료` 가 덮개 경고를 거친다
- [ ] 창을 닫아도 잠자기 방지가 유지된다
- [ ] Dock 아이콘이 그대로 있다
- [ ] 문자열 3언어(ko/en/ja)
