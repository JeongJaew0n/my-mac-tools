# spec — tool-defaults + 설정 메뉴 분리

## 목표

1. `설정` 을 앱 메뉴 안이 아니라 **메뉴 막대의 독립 항목**으로 뺀다.
2. **잠자기 방지**와 **덮어도 작업**에 `기본값으로 저장` · `기본값으로 되돌리기` 를 둔다.

## 1. 설정 메뉴 분리

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 앱 메뉴의 `설정…` | **없앤다.** `CommandGroup(replacing: .appSettings) { }` | 두 군데 있으면 어느 쪽이 정본인지 알 수 없다 |
| 새 자리 | `CommandMenu` 로 메뉴 막대에 `설정` 을 만든다 | 이미 `언어` 가 같은 방식으로 나와 있다 |
| 창을 여는 법 | `SettingsLink` | macOS 14+ 의 표준. `Settings` 씬을 여는 공식 경로다 |
| `⌘,` | 유지한다 | 자리를 옮겼다고 손에 익은 단축키를 뺄 이유가 없다 |

## 2. 기본값 저장·되돌리기

### 무엇이 기본값인가

| Tool | 저장하는 값 |
|---|---|
| 잠자기 방지 | 유지 시간(시·분) · 화면 모드 · 화면 끄기까지 · 끝나면 Mac잠자기 |
| 덮어도 작업 | 유지 시간(시·분) |

**지금은 아무것도 저장되지 않는다.** 앱을 끄면 화면에서 고른 값이 사라지고 다음 실행에
코드에 박힌 값(0시 0분, 5초, 맥북 기본설정대로, 끔)으로 돌아간다.

### 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 저장 자리 | `UserDefaults` — `default.sleep.*` · `default.lid.*` | |
| **앱을 켤 때** | 저장된 기본값으로 시작한다 | 이게 없으면 `저장` 이 아무 일도 안 하는 버튼이 된다. 저장의 뜻은 "다음에도 이걸로 시작" 이다 |
| 저장된 것이 없으면 | 코드에 박힌 값을 쓴다 | 지금 동작 그대로다 |
| `되돌리기` 의 대상 | **저장된 기본값.** 저장한 적이 없으면 코드에 박힌 값 | |
| 버튼 상태 | 지금 값이 기본값과 **같으면 둘 다 잠근다** | 눌러도 아무 일이 없는 버튼을 누르게 두지 않는다 |
| 돌고 있는 세션 | **영향 없다.** 값만 바뀐다 | `caffeinate` 인자는 `시작` 을 누른 시점에 정해진다. 도는 중에 되돌렸다고 세션이 바뀌면 놀란다 |
| 자리 | 각 탭의 설정 블록 **아래**, 시작 버튼 **위** | 설정에 딸린 동작이므로 설정 옆에 둔다. 시작 버튼과 섞이면 무엇이 주 동작인지 흐려진다 |

## 화면

```
 유지 시간      [0] 시  [00] 분
 화면           [맥북 기본설정대로]
 화면 끄기까지  [3] 초
 □ 끝나면 Mac잠자기 모드

 [기본값으로 저장]  [되돌리기]        ← 값이 기본값과 같으면 둘 다 흐려진다

 [        시작        ]
```

## 완료 조건

- 메뉴 막대에 `설정` 이 독립 항목으로 있고, 앱 메뉴에는 `설정…` 이 **없다**
- `⌘,` 로 여전히 열린다
- 두 탭에서 값을 바꾸고 `기본값으로 저장` → **앱을 다시 켜면 그 값으로 시작**한다
- 값을 바꾼 뒤 `되돌리기` → 저장된 기본값으로 돌아온다
- 기본값과 같으면 두 버튼이 잠긴다
- 세션이 도는 중에 되돌려도 그 세션은 그대로다
- 문구가 ko · en · ja 세 언어로 나온다
