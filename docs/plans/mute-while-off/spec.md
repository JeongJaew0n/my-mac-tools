# spec — 화면 끌 때 음소거

## 요구사항
"화면 끄기 할 때 자동으로 음소거 되는 옵션 넣어줘." (2026-11-15)

## 확정된 결정
| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 대상 | 잠자기 방지의 ScreenMode `keepOff` 세션. 그 밖의 모드에서는 토글을 잠근다 | 화면을 끄는 모드는 `keepOff` 뿐이다 |
| 시점 | 카운트다운이 끝나 **화면을 처음 끄는 순간** 음소거한다. 화면이 깨어난 유예 중에도 풀지 않는다 | "화면 끄기 할 때". 유예마다 풀었다 걸면 소리가 들락날락한다 |
| 되돌림 | 세션이 끝나면(정지·만료·앱 종료) **시작 전 상태로** 되돌린다. 이미 음소거였으면 그대로 둔다 | 실측 — 이 맥의 스피커는 이미 음소거 상태였다. 무조건 풀면 사용자가 꺼둔 소리를 앱이 켠다 |
| 장치 | 음소거한 그 출력 장치(ID)를 되돌린다. 도중에 기본 출력이 바뀌어도 새 장치는 건드리지 않는다 | 사용자가 바꾼 장치에 앱이 손대지 않는다 |
| 방법 | CoreAudio `kAudioDevicePropertyMute` (출력 범위, main 요소). 권한 불필요 | 실측 — MacBook Pro 스피커에서 main 요소가 있고 바꿀 수 있다 |
| 실패 | 장치가 음소거를 못 하면 진행 줄에 알린다. 세션은 계속 돈다 | 조용히 실패하면 고장으로 보인다 |
| 설정 저장 | 기본값(`ToolDefaults.Sleep`)에 넣는다. 예전 저장값에는 이 항목이 없으므로 없으면 꺼짐으로 읽는다 | 단축키·메뉴바는 저장한 기본값으로 켠다. 항목이 없다고 저장값 전체를 버리면 사용자의 기본값이 사라진다 |
| API | `sleep.get` 에 보이고 `sleep.start` 에서 줄 수 있다 | 다른 세션 설정과 같게. `docs/api.md` 와 함께 고친다 |

## 논의에서 생략한 축
| 결정 축 | 생략 이유 |
|---|---|
| 앱이 죽을 때 | 크래시하면 음소거가 남는다. 되돌릴 프로세스가 없다 — README 에 적는다 |
| 마이크 | 요구는 소리 끄기다. 입력은 건드리지 않는다 |
