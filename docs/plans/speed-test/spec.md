# spec — speed-test

## 목표

인터넷 속도를 이 앱에서 잰다. 버튼 하나로 **다운로드 · 업로드 · 응답성 · 지연**을 보여준다.

조사와 실측 근거는 `context.md`.

## 확정한 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 측정 수단 | **macOS 내장 `networkQuality`** 를 `Process` 로 실행한다. `-c` 로 JSON 을 받는다 | 설치할 것이 없고 Apple 이 관리한다. 서버도 Apple CDN 이 고른다(실측 — 서울 엣지). 앱은 이미 `caffeinate` · `pmset` 을 같은 방식으로 띄운다 |
| 언제 재나 | **사용자가 누를 때만.** 자동·주기 측정은 하지 않는다 | 1회에 **21초, 147 MB** 를 썼다(실측). 회선이 빠를수록 더 쓴다. 이 앱의 다른 화면처럼 폴링하면 안 되는 종류다 |
| 측정 중 | 진행 표시 + **취소 가능** (`Process.terminate`) | 21초는 기다리기에 길다. 잘못 눌렀을 때 데이터를 다 쓰게 두지 않는다 |
| 시간 상한 | `-M` 으로 최대 실행 시간을 건다 | 느린 회선에서 끝없이 돌지 않게. 값은 아래 *열린 결정* |
| 보여줄 값 | 다운로드 · 업로드(Mbps), 응답성(RPM), 기본 지연(ms), 인터페이스, 측정 서버 | `networkQuality -c` 의 `dl_throughput` · `ul_throughput`(bit/s, 실측으로 단위 확인) · `responsiveness` · `base_rtt` · `interface_name` · `test_endpoint` |
| 실패 | 종료 코드·stderr 를 그대로 보여준다 | 오프라인·서버 오류를 "0 Mbps" 로 그리면 거짓이다 |

## 열린 결정 — 구현 전에 확정

| # | 축 | 선택지 | 추천 |
|---|---|---|---|
| 1 | **배치** | 새 Tool(다섯째 탭) / 로컬호스트 탭 안 | **새 Tool.** 로컬호스트는 *내 맥의 포트*, 이것은 *바깥 회선*이라 다루는 대상이 다르다 |
| 2 | **비싼 회선** | 그냥 잰다 / 확인을 받는다 / 막는다 | **확인을 받는다.** `NWPathMonitor` 의 `isExpensive`(테더링·셀룰러)·`isConstrained`(저데이터 모드)면 한 번 묻는다. 핫스팟으로 150 MB 는 무시할 양이 아니다 |
| 3 | **기록** | 마지막 1회만 / 최근 N회 / 안 남김 | **최근 10회.** 속도는 한 번보다 비교가 의미 있다 |
| 4 | **최대 시간** (`-M`) | 15 / 30 / 60초 | **30초.** 실측 21초에 여유를 둔다 |
| 5 | **병렬·순차** | 기본(병렬) / `-s` 순차 | **병렬.** 순차는 각 값이 정확하지만 시간이 두 배다. 고급 옵션으로 둘 수 있다 |
| 6 | **메뉴바** | 항목 추가 / 안 함 | **추가하지 않는다.** 결과를 볼 자리가 메뉴에 없고, 21초짜리 작업을 메뉴에서 시작하면 진행을 보여줄 곳이 없다 |
| 7 | **에이전트 API** | `network.test` 추가 / 안 함 | **추가하되 비동기로.** 클라이언트 소켓 타임아웃이 10초라 21초짜리 동기 호출은 끊긴다. 시작 → 상태 조회 두 메서드로 나눈다 |

## 완료 조건 (초안)

- 버튼을 누르면 21초 안팎에 네 값이 나온다
- 측정 중 취소하면 `networkQuality` 가 바로 끝나고 화면이 측정 전으로 돌아간다
- 오프라인이면 0 이 아니라 실패 이유가 보인다
- 비싼 회선이면 시작 전에 묻는다 (2번을 그렇게 정했다면)
- 창을 닫거나 탭을 옮겨도 측정이 엉키지 않는다 — 계속할지 멈출지는 구현 때 정한다
- 문구 ko · en · ja

## 범위에서 빼는 것

- **자동·주기 측정** — 데이터와 전력
- **서버 고르기** — `networkQuality` 가 고른다. `-C` 로 바꿀 수 있지만 쓸 이유가 없다
- **속도 그래프** — 기록을 남긴다면 그 뒤의 이야기다
