# spec — 화면 끈 채로 작업 단축키

## 요구사항
"화면 끈 채로 작업 단축키 만들어주라. 단축키는 화면에서 제어할 수 있게 해줘." (2026-11-14)

## 확정된 결정
| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 대상 | 잠자기 방지 Tool 의 ScreenMode `keepOff`(끈 상태로 유지) 세션 | "화면 끈 채로 작업" = 시스템 잠자기는 막고 화면은 끈다 |
| 동작 | **토글** — 꺼져 있으면 켜고, 돌고 있으면(어느 모드든) 끈다 | 사용자 선택. 화면이 꺼진 채 일하다 돌아와 같은 키를 누르면 화면이 켜진 채로 끝난다 |
| 켤 때 값 | **저장한 기본값**에 화면 모드만 `keepOff` 로 덮어쓴다. 덮개 규칙(`enforceLidRule`)도 메뉴바와 같이 | 사용자 선택. 메뉴바와 같은 규칙 — 창을 안 보고 누르는 키라 기억하는 값으로 돈다 |
| 지정 화면 | 잠자기 방지 탭, 시작 버튼 위. 화면 가리기와 같은 `ShortcutRecorder`. 세션이 돌아도 잠그지 않는다 | "화면에서 제어". 설정 블록은 도는 동안 잠기지만 단축키는 세션 값이 아니다 |
| 겹침 | 화면 가리기와 같은 조합은 받지 않고 이유를 보인다 | 한 조합에 두 동작이 걸리면 어느 쪽이 먼저인지 정할 수 없다 |
| 등록 | `HotKeyCenter` 가 여러 개를 id 로 구분해 등록 | 지금은 하나만 받아, 두 번째를 등록하면 화면 가리기 단축키가 풀린다 |

## 논의에서 생략한 축
| 결정 축 | 생략 이유 |
|---|---|
| API | 단축키는 사람이 누르는 것. `sleep.start screenMode=keepOff` 가 이미 있다 |
| 호환성 | 화면 가리기 단축키 저장 키(`coverShortcut`)는 그대로 |
