## 방법

- 리뷰: 영역별 네 갈래(화면·설정 / 전원·프로세스 / API·수명주기 / 화면가리기·로컬호스트·속도·Mac정보)를
  병렬로 돌리고, 나온 지적을 **실제 코드·실측으로 다시 확인한 것만** 고친다.
- 테스트: 테스트 타깃이 없다. 빌드 + 설치본 API 호출 + 실측 + 화면 밖 렌더링 캡처로 확인한다.
  실제 창은 사용자의 '화면 끔 유지' 세션 때문에 캡처할 수 없어, 앱 소스로 `ContentView` 를
  화면 밖 창에 그려 PNG 로 찍었다(scratchpad 의 harness).
- 다시 설치할 때마다 돌던 잠자기 방지 세션을 같은 설정으로 되살린다.
