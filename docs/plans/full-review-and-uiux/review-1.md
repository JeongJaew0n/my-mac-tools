| B1·C2 | 앱을 끄거나 앱이 죽어도 `caffeinate` 가 남는다 — 시간 제한 없는 세션이면 맥이 영영 유휴 잠자기를 못 함 | **수정** — `-w <앱 pid>` | 수정 전: 앱 종료 뒤 옛 caffeinate 27920 생존(실측). 수정 후: 종료 뒤 40311 스스로 끝남, 앱이 죽었을 때도 같이 끝남(실측). `-t` 와 `-w` 를 함께 주면 먼저 오는 쪽에 끝남(실측) |
| C1 | 클라이언트가 먼저 끊으면 응답을 쓰다 SIGPIPE 로 앱이 죽는다 | **수정** — `signal(SIGPIPE, SIG_IGN)` + 소켓별 `SO_NOSIGPIPE` | 리뷰가 제안한 `SO_NOSIGPIPE` 만으로는 **실제 앱이 죽었다**. 이미 끊긴 연결을 accept 하면 옵션이 `EINVAL` 로 거부됨(실측). 프로세스 전체 무시를 더한 뒤 끊긴 연결 30~40번에도 생존(테스트 서버·설치본 모두). `docs/troubleshootings/reusable/so-nosigpipe-fails-on-disconnected-socket.md` |
| B2 | 켜 둔 채 앱이 죽으면 `disablesleep=1` 이 주인도 만료도 없이 남는다 | **수정** — 주인·만료 시각을 `UserDefaults`(`lidSession`)에 남기고 다음 실행이 이어받음 | 테스트 서버로 재현: 만료 지난 기록 → 뜨자마자 `SleepDisabled` 0 으로 끔·기록 지움 / 만료 전 기록 → `turnedOnByThisApp: true` 로 이어받음(실측, 끝나고 0 으로 원복) |

## 테스트 방법

- 빌드: `swift build` 경고 0
- API: 설치본과, **소켓 경로만 바꾼 테스트 서버**(앱 소스 + 작은 main, scratchpad)로 실측.
  실제 앱을 죽이는 시험(SIGPIPE·덮개 크래시)은 테스트 서버로 했다
- 다시 설치할 때마다 사용자의 잠자기 방지 세션(화면 끔 유지·무제한)을 같은 설정으로 되살렸다.
  SIGPIPE 시험 중 실제 앱이 한 번 죽었고(수정 전 `SO_NOSIGPIPE` 만 있던 상태), 곧바로 되살렸다
