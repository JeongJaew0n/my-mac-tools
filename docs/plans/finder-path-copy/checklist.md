## 미확인 — 코드를 고쳐 재빌드하면 권한이 풀리는가

TCC 는 CDHash 에 권한을 묶는다. 소스가 같으면 재빌드해도 해시가 같은 것은 확인했지만,
코드를 고치면 해시가 바뀐다. 이번 작업으로 실제로 바뀌었다.

```
이전: CDHash=aed0539fcdb04285c8d251ea54405c3dd9d663e4
이후: CDHash=1b7f0bf0b4ea625a072bfcd205fc107825f9df43
```

**즉 앱을 수정해 다시 설치할 때마다 자동화 권한을 다시 물어볼 가능성이 있다.** 실제로
그런지는 권한을 한 번 허용한 뒤 코드를 고쳐 재설치해봐야 안다.
