# spec — 캡처 편집

## 요구사항
사용자 지시(2026-11-23, 세션마스터 대리 입력): ⌃⌘⇧3 으로 화면을 클립보드에 캡처한 뒤, 빨간 펜으로 그리거나
글자를 조금 넣고 다시 클립보드에 넣고 싶다. 새 Tool "캡처 편집".

## 확정된 결정
| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 여는 길 | 전역 단축키(기본 ⌃⌘⇧E), Tool 탭의 버튼, 메뉴바, API `capture.edit` | 요구사항. 단축키는 `HotKeyCenter` 세 번째 자리(`captureEdit`) |
| 단축키 기본값 | 저장한 적이 없으면 ⌃⌘⇧E. 지우면(`Delete`) 지운 채로 기억한다 | 요구사항. 지운 것과 저장한 적 없는 것을 구분해야 지운 단축키가 되살아나지 않는다 |
| 단축키 바꾸는 곳 | Tool 탭의 기록 칸 | 다른 두 단축키(화면 가리기·화면 끈 채로 작업)와 같은 자리 |
| 권한 | 클립보드 읽기·쓰기와 Carbon 단축키만. 화면 기록·손쉬운 사용·알림 권한 없음 | 요구사항 |
| 클립보드 감시 | 하지 않는다. 누를 때만 읽는다 | 요구사항 |
| 그림 없음 | 화면 가운데 작은 안내 창을 2초 띄웠다 지운다 | 사용자 선택. 알림 센터는 알림 권한을 묻는다 |
| 창 크기 | 그림 비율을 지키며 주 화면 보이는 영역의 가로·세로 절반 안에 맞춘다. 작은 그림은 원본 크기. 끌어서 바꿀 수 있다 | 사용자 선택 |
| 창이 이미 열려 있을 때 | 단축키를 다시 누르면 그 창을 앞으로 낸다. 새 그림으로 바꾸지 않는다 | 그리던 것을 말없이 잃지 않게 |
| 도구 | 펜(기본) · 네모 · 화살표 · 글자. ⌘Z 되돌리기 | 사용자 선택(네모·화살표 포함) |
| 색 · 굵기 | 빨강(기본)·노랑·파랑·검정·흰색 / 2·4·8pt(기본 4) | 사용자 선택. 색은 라이트·다크와 상관없이 같은 값(결과 그림이 화면 모양을 따라 바뀌면 안 된다) |
| 좌표 | 표시는 줄여 보여도, 그린 것은 **그림의 포인트 좌표**로 기억한다 | 창 크기를 바꿔도 그린 자리가 그림에 붙어 있다 |
| 글자 | 누른 곳에 입력 칸. Enter 로 넣고 Esc 로 취소. 크기는 굵기에 따라 시스템 글자 크기 셋(title3 · title1 · largeTitle) | 크기를 새로 짓지 않고 시스템 단계를 쓴다 |
| Enter · ⌘C | 글자를 입력하는 중이 아니면 결과를 클립보드에 넣고 닫는다. 입력 중의 Enter 는 글자만 넣는다 | Enter 가 두 뜻이라 입력 중에는 입력이 먼저다 |
| Esc | 입력 중이면 입력만 취소, 아니면 그냥 닫는다(클립보드는 그대로) | 요구사항 |
| 결과 | 원본 픽셀 크기(레티나면 2배 그대로) PNG 를 `public.png` 로 클립보드에 넣는다. 해상도 정보(DPI)를 남겨 붙여넣을 때 원래 크기로 보인다 | 요구사항 |
| 굵기 단위 | 화면 포인트. 레티나 캡처에서는 그림 픽셀로 2배가 된다 | 사용자 선택지에 적은 대로 |
| 화살표 머리 | 길이는 굵기의 4배(최소 10pt), 벌어짐 ±25° | 정한 값 — 눈으로 보고 고친다. `design/tokens.json` 의 `product.capture` |

## 논의에서 생략한 축
| 축 | 이유 |
|---|---|
| 파일로 저장 | 요구는 클립보드다. 저장은 붙여넣은 앱에서 한다 |
| 다시 실행(⌘⇧Z) | 요구는 되돌리기뿐이다 |
| 그린 것 옮기기·지우개 | 되돌리기로 충분하다는 범위 |
