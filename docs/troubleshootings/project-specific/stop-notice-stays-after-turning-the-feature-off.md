# 껐는데 "직접 정지를 눌러주세요" 가 계속 떠 있다

## 증상

유지 시간이 끝났는데 자동 해제에 실패해 빨간 안내가 떴다. 안내대로 정지를 눌러 껐는데도
그 문구가 사라지지 않았다.

## 원인

`autoStopFailed` 를 `false` 로 되돌리는 곳이 **"켤 때" 하나뿐**이었다. 끌 때도, 밖에서
꺼졌을 때도 내려놓지 않아 꺼진 상태에 켜졌을 때의 문구가 남았다.

[`status-off-but-countdown-keeps-running.md`](status-off-but-countdown-keeps-running.md)
와 같은 클래스다 — **켜져 있을 때만 의미가 있는 값이 꺼진 뒤에도 살아 있었다.**

## 해결

2026-09-15 수정. `refreshFromSystem()` 이 꺼진 것을 확인하면 카운트다운·실패 표시·소유권을
**한곳에서 전부** 내려놓는다. 경로마다 따로 지우지 않는다.

## 재발 방지

코드에서 **플래그를 세우는 곳과 내리는 곳의 수를 센다.** 내리는 경로가 세우는 경로보다
적으면 거의 항상 이 버그다.

상태 해제는 경로별로 흩지 말고 한곳으로 모은다.
