# checklist — review-shortcut-hosts

`3ce43f3..eeb55b4`(hosts 열기, 화면 끈 채로 작업 단축키) 코드리뷰에서 나온 10건을 하나씩 확인하고 고친 기록이다.
`(실측)` 은 명령·캡처로 확인한 것이다.

## 판정
| # | 지적 | 판정 | 처리 |
|---|---|---|---|
| 1 | 기록 중에 이미 걸린 조합을 누르면 기록기 대신 핫키가 발동 — 겹침 검사가 돌지 않음 | 맞음. 기록기에 핫키를 푸는 코드가 없었다 | `HotKeyCenter.pause/resume`, 기록기가 기록하는 동안 부른다 |
| 2 | 등록 실패해도 저장·표시는 새 조합 | 맞음. `register` 의 결과를 버렸다 | `set` 이 `Outcome` 을 돌려주고 `.done` 일 때만 저장·표시. 실패하면 원래 단축키를 되살린다 |
| 3 | hosts 수만 줄이면 메인에서 읽고 전부 그림 | 맞음(이 맥은 9줄) | 메인 밖에서 읽기 + `LazyVStack` |
| 4 | 창 없이 시작하면 `onShortcut` 이 비어 단축키가 무반응 | 이번 변경만의 문제가 아님 | 고치지 않음 — 메뉴바 항목·API 서버도 같은 `onAppear` 에서 붙는다. 고치려면 앱 시작 구조를 바꿔야 한다 |
| 5 | 겹침 안내가 상대 단축키를 바꿔도 남음 | 맞음 | 어느 자리든 바꾸기에 성공하면 안내를 비운다 |
| 6 | 'no application' 영어가 현지화 문장에 끼어듦 | 맞음 | `hosts.noApp` ko/en/ja |
| 7 | 겹침 규칙이 화면 두 곳에 복사 | 맞음 | `HotKeyCenter.set` 한곳에서 검사 |
| 8 | 단축키 저장·적용 코드가 두 관리자에 복사 | 맞음 | `Shortcut.load/save` + `HotKeyCenter.set` 으로 줄임 |
| 9 | `defaultEditor` 를 그릴 때마다 조회 | 맞음(체감 없음) | `reload()` 때 한 번 조회해 기억 |
| 10 | 용어집에 단축키 자리 없음 | 맞음 | 용어집에 '단축키 자리' 추가 |
