# spec — tabbed-window

## 목표
한 창에 세로로 쌓여 있던 두 기능을 상단 탭으로 분리해, 한 번에 한 기능만 보이게 한다.
창이 320x569 까지 길어진 것을 줄이고, 기능이 늘어도 세로로 무한히 자라지 않는 구조를 만든다.

## 현재 구조
`ContentView` 하나의 `VStack` 에 전부 들어 있다.

```
제목 "MyMacTools"
상태 점 + "작업 중 / 대기 중"        ┐
유지 시간 · 화면 끄기 · 토글 2개      │ 화면 끄고 작업 (BlackWorkManager)
[시작]                              │
남은 시간                           ┘
───────── Divider ─────────
상태 점 + 제목 + "켜짐 / 꺼짐"        ┐
유지 시간                           │ 덮개 닫아도 작업 진행 (LidWorkManager)
주의사항 4줄                        │
[시작] · 남은 시간                   ┘
```

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 상태 가시성 | 탭 라벨에 상태 점(녹색=동작 중 / 회색=꺼짐)을 붙인다 | 둘 다 **시스템 상태**를 바꾸고, 특히 덮개 기능은 앱을 꺼도 남는다. 탭 뒤에 숨으면 켜둔 것을 잊는다. 공간을 거의 안 먹고 어느 탭에 있든 둘 다 보인다 |
| 탭 구현 | `TabView` 대신 `HStack` + `Button(.accessoryBar)` 로 직접 그린다 | macOS 의 `.tabItem` 은 이미지를 template 으로 렌더링해 녹색 점이 회색으로 죽을 수 있다. 직접 그리면 기존 `Circle().fill(...)` 관용구를 그대로 재사용할 수 있고 색이 확실히 나온다 |
| 창 크기 | 긴 쪽 탭에 맞춘 고정 높이 | `.windowResizability(.contentSize)` 라 탭마다 높이가 다르면 전환할 때마다 창이 튄다 |
| 탭 기억 | 마지막으로 본 탭을 `UserDefaults` 에 저장 | `L10n` 이 `appLanguage` 를 같은 방식으로 저장하는 선례가 있다. 주로 쓰는 기능이 바로 나온다 |
| 제목 | 본문의 `Text("MyMacTools")` 를 없애고 창 타이틀바에 맡긴다 | 탭바가 생기면 상단이 제목·탭·상태 3단이 되어 무겁다. 세로 공간도 아낀다 |

## 범위
- 포함:
  - `ContentView` 를 탭 컨테이너로 바꾸고, 기존 두 묶음을 각각 하위 뷰로 분리
  - 탭바(상태 점 + 이름 + 선택 표시)
  - 탭 선택 저장/복원
  - 탭 이름 2개 `L10n.Key` + `ko/en/ja` 추가
- 제외:
  - `BlackWorkManager` · `LidWorkManager` 로직 변경 없음
  - 권한·원복·상태 판정 로직 변경 없음
  - 언어 메뉴는 지금처럼 메뉴바에 둔다

## 탭이 끊는 연결 — 추가 작업 불필요
`A` 탭의 "끝나면 Mac잠자기 모드" 토글은 `lid.isRunning` 에 따라 잠긴다.
탭이 나뉘면 잠긴 이유가 다른 탭에 있게 되지만, 기존 문자열이 기능 이름을 직접 부르므로
탭을 옮기지 않아도 이유를 읽을 수 있다.

```
"caption.sleepBlockedByLid" = "'덮개 닫아도 작업 진행'이 켜져 있는 동안에는 잠자기로 전환할 수 없습니다";
```

탭 라벨의 녹색 점이 이를 뒷받침한다. 두 매니저는 그대로 `MyMacToolsApp` 에서 주입되므로
탭이 나뉘어도 서로의 상태를 읽는 데 문제가 없다.

## 완료 조건 (Definition of Done)
- [ ] 탭 두 개로 전환되고 한 번에 한 기능만 보인다
- [ ] 탭 라벨의 상태 점이 각 기능의 실제 동작 여부를 따라간다 (녹색/회색)
- [ ] 덮개 기능이 켜진 채 다른 탭에 있어도 그 사실이 탭 라벨에서 보인다
- [ ] 탭을 전환해도 창 크기가 변하지 않는다
- [ ] 앱을 껐다 켜면 마지막으로 보던 탭이 나온다
- [ ] 창 타이틀바에 "MyMacTools" 가 나온다 (`CFBundleName` 기본값으로 충분한지 확인 필요)
- [ ] `A` 탭에서 "끝나면 Mac잠자기 모드"가 잠겼을 때 이유 문구가 그대로 보인다
- [ ] 기존 두 기능의 동작에 회귀가 없다
- [ ] 탭 이름이 ko/en/ja 3개 언어로 모두 나온다

## 비고 / 확인 필요
- `Button(.accessoryBar)` 로 선택 상태가 충분히 구분되는지 실물로 확인한다.
  부족하면 선택된 탭에 배경을 직접 그린다.
- 창 타이틀바 제목은 `WindowGroup` 에 명시하지 않으면 `CFBundleName` 을 쓴다고 보고 있다.
  실제로 그런지 구현 중 확인한다. 아니면 `.navigationTitle` 로 명시한다.
- 고정 높이는 두 탭 중 긴 쪽을 실측해 정한다. 주의사항 4줄이 있는 덮개 탭이 더 길 것으로 본다.
