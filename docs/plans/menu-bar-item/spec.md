# spec — menu-bar-item

## 목표
맥북 상단 상태 막대에 MyMacTools 아이콘을 띄운다. 창을 열지 않고도 **무엇이 돌고 있는지
보이고**, 기능을 켜고 끌 수 있게 한다.

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| Dock 아이콘 | **유지한다.** 메뉴바는 추가 | 기존 동작을 하나도 바꾸지 않아 되돌리기 쉽다 |
| 클릭 동작 | 드롭다운 메뉴 (`NSMenu`) | 메뉴바 앱의 관례이고 가장 가볍다 |
| 메뉴 구성 | 기능 3개 토글 + `창 열기` + `종료` | |
| 상태 표시 | 하나라도 돌고 있으면 **글리프 우측 하단에 초록 점**. 아니면 아무것도 없음 | 채움/비움은 옆에 비교 대상이 없으면 구분이 안 됐다. 덮개 기능은 앱을 꺼도 시스템에 남으므로 켜둔 것을 잊지 않게 하는 값어치가 크다 |
| 구현 | **`NSStatusItem` 직접.** `MenuBarExtra` 를 쓰지 않는다 | 아래 참조 |
| 권한 | 없음 | `NSStatusItem` 생성에 권한이 필요 없는 것을 확인했다 |

## 메뉴 모양

```
┌─────────────────────────┐
│ ✓ 잠자기 방지            │
│   덮어도 작업            │
│ ✓ 화면 가리기            │
├─────────────────────────┤
│ 창 열기                  │
│ 종료                     │
└─────────────────────────┘
```

기능 항목은 체크마크(`NSMenuItem.state`)로 그린다. 색 점(`Circle().fill(.green)`)을 쓰지 않는 이유는 메뉴가
이미지를 template 으로 렌더링해 **녹색이 회색으로 죽을 수 있기** 때문이다. 탭바를 만들 때
같은 이유로 기성 스타일을 피했다(`docs/plans/tabbed-window/spec.md`). 메뉴에서는 체크마크가
관례이기도 하다.

## 바뀌는 기존 동작 — 창을 닫아도 세션이 안 끊긴다

지금은 창을 닫으면 `onDisappear` 에서 `BlackWorkManager.stop()` 이 돌아 **잠자기 방지가
꺼진다.** 메뉴바에서 켜고 창을 닫으면 그대로 꺼져버리므로 이 규칙은 더 이상 맞지 않는다.

창 닫기는 세션을 끊지 않게 바꾼다. 세션을 끝내는 것은 **정지 또는 앱 종료**다. 종료할 때
덮개 기능 경고가 뜨는 흐름은 그대로다.

## 중복 규칙 한곳으로

덮개 기능을 켤 때 "끝나면 Mac잠자기 모드" 를 함께 내려야 한다. `disablesleep=1` 이면
`pmset sleepnow` 가 거부되기 때문이다
(`docs/troubleshootings/reusable/pmset-sleepnow-refused-when-disablesleep-is-1.md`).

지금은 이 규칙이 `ContentView` 에만 있다. 메뉴에서도 켤 수 있게 되므로 **두 곳이 되기 전에**
한곳으로 모은다. 상태를 세우는 곳과 내리는 곳이 갈라져서 난 버그가 이미 두 번 있었다.

## 범위 밖

- 메뉴바 전용 앱으로 전환(`LSUIElement`)
- 메뉴에서 유지 시간·사진 같은 설정 변경 — 창에서 한다
- 남은 시간 표시

## 완료 조건

- [ ] 상태 막대에 아이콘이 뜬다
- [ ] 기능 3개를 메뉴에서 켜고 끌 수 있다
- [ ] 돌고 있는 기능에 체크가 보인다
- [ ] 하나라도 돌면 아이콘 모양이 바뀐다
- [ ] `창 열기` 로 닫았던 창이 다시 열린다
- [ ] `종료` 가 덮개 경고를 거친다
- [ ] 창을 닫아도 잠자기 방지가 유지된다
- [ ] Dock 아이콘이 그대로 있다
- [ ] 문자열 3언어(ko/en/ja)


## 초록 점을 어떻게 그리는가 — 세 방법을 재봤다

메뉴바는 아이콘을 **template 으로 렌더링**한다. 색이 그냥은 살지 않는다. 스크래치 앱으로
셋을 나란히 띄워 캡처해 비교했다.

| 방법 | 결과 |
|---|---|
| SwiftUI `ZStack` 에 `Circle().fill(.green)` | **초록이 죽는다.** template 로 렌더링된다 |
| `isTemplate = false` 로 합성한 `NSImage` | 초록은 살지만 **글리프 색이 굳는다.** 다른 아이콘은 흰데 혼자 검게 남았다 |
| `NSStatusItem` 직접 + template 글리프 + 점은 **별도 뷰** | **둘 다 성립한다** |

세 번째로 간다. `MenuBarExtra` 는 `NSStatusItem` 의 버튼을 내주지 않아 이 구성을 만들 수
없으므로 쓰지 않는다.

점 위치는 **버튼이 아니라 글리프 기준**으로 잡는다. 버튼 높이(32.5pt)가 메뉴바(22pt)보다
커서, 버튼 바닥에 붙이면 잘린다.

```
button.bounds = (0, 0, 39.5, 32.5)   isFlipped = true
메뉴바 두께    = 22.0
→ dot = (글리프 우측 하단, 5x5)
```

### 글리프 크기는 못 박는다

`SymbolConfiguration(pointSize:)` 만으로는 결과 크기가 예측되지 않는다. `pointSize: 16`
으로 잡았더니 **22pt 짜리 이미지**가 나왔고, 메뉴바가 딱 22pt 라 위아래가 잘렸다.

그래서 심볼을 불러온 뒤 가로세로 비를 지키며 **높이를 16pt 로 직접 지정**한다. 옆의
다른 메뉴바 아이콘들과 크기가 맞는 것을 캡처로 확인했다.
