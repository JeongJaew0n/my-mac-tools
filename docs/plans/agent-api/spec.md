# spec — agent-api

## 목표

Claude Code 나 다른 에이전트가 이 앱의 기능을 **셸에서** 쓸 수 있게 한다. 상태를 읽고,
Tool 을 켜고 끄고, 카페인·포트 목록을 받아간다.

## 확정된 결정

| 결정 축 | 확정 내용 | 근거 |
|---|---|---|
| 전송 | **유닉스 도메인 소켓.** `~/Library/Application Support/MyMacTools/api.sock` | 아래 *왜 포트를 열지 않는가* |
| 접근 제어 | **파일 권한 `0600`.** 토큰도 암호도 없다 | 소켓 파일을 열 수 있는 것은 이 사용자뿐이다. 토큰을 두면 그 토큰을 어디에 둘지가 새 문제가 된다 |
| 프로토콜 | **줄 단위 JSON.** 요청 한 줄 → 응답 한 줄 | `nc -U` 와 python 세 줄로 된다. 프레이밍을 직접 만들지 않는다. **HTTP 가 아니므로 `curl --unix-socket` 은 안 된다** — 처음 이 표에 `curl` 을 적었는데 실측에서 빈 응답이 나와 고쳤다 |
| 응답 모양 | `{"ok":true,"result":…}` 또는 `{"ok":false,"error":{"code":…,"message":…}}` | 에이전트가 `ok` 하나만 보고 갈라낼 수 있다 |
| 클라이언트 | `scripts/mymactools` (python3). 소켓을 직접 두드려도 된다 | 에이전트는 셸을 쓴다. `/usr/bin/python3` 는 macOS 기본이라 의존성이 없다 |
| 쓰기 작업 | **허용한다.** 단 아래 *거부하는 것* 은 예외 | 읽기만 주면 "상태를 보고 조치" 라는 쓸모가 절반으로 준다 |
| 시스템 구성요소 중지 | **거부한다** (`forbidden`) | 앱은 사람에게 한 번 더 묻고 끈다. API 호출자에게는 물어볼 사람이 없다. 물을 수 없으면 하지 않는다 |
| 덮개 Tool 켜고 끄기 | **거부한다** (`needsHuman`) | `pmset` 에 관리자 인증이 필요하고, 규칙이 없으면 암호창이 뜬다. 에이전트 호출로 암호창이 튀어나오는 것은 사용자가 예상할 수 없는 일이다 |
| 앱이 안 떠 있을 때 | 소켓이 없다. 클라이언트가 **그 사실을 말한다** | 조용히 실패하면 에이전트가 "기능이 없다" 고 오해한다 |
| 서버 수명 | 앱과 같다. 창을 닫아도 살아 있다 | 메뉴바가 생기면서 창 닫기가 세션을 끊지 않게 바뀌었다. API 도 같은 규칙을 따른다 |

## 왜 포트를 열지 않는가

로컬 HTTP 서버가 에이전트에게는 가장 익숙하다. 그런데 이 앱에는 **듣고 있는 포트를
보여주는 Tool** 이 있다. HTTP 서버를 열면 자기 목록에 자기가 나타난다. 그것 자체가
틀린 것은 아니지만,

- 포트는 같은 맥의 **다른 사용자와 다른 프로그램에도** 열려 있다. 그래서 토큰이 필요해진다
- 유닉스 소켓은 파일 권한이 그 일을 대신한다. `0600` 이면 이 사용자만 연다
- `nc -U` 한 줄, python 세 줄로 부른다

그래서 소켓을 골랐다.

## 메서드

### 읽기

| 메서드 | 파라미터 | 결과 |
|---|---|---|
| `status` | — | 네 Tool 의 현재 상태 한 번에 |
| `sleep.get` | — | 잠자기 방지 상태·설정 |
| `lid.get` | — | 덮개 상태 (커널의 지금 값으로 갱신 후) |
| `cover.get` | — | 화면 가리기 상태 |
| `caffeinate.list` | — | 돌고 있는 `caffeinate` 전부 |
| `ports.list` | `category` `search` (둘 다 선택) | 듣고 있는 localhost 포트 |

### 쓰기

| 메서드 | 파라미터 | 비고 |
|---|---|---|
| `sleep.start` | `hours` `minutes` `screenMode` `sleepWhenDone` `displayDelaySeconds` (모두 선택) | 준 것만 바꾸고 시작한다 |
| `sleep.stop` | — | |
| `cover.start` | — | 사진이 없으면 `preconditionFailed` |
| `cover.stop` | — | |
| `caffeinate.stop` | `pid` (필수) | 이 앱 것이면 매니저를 거친다 |
| `ports.stop` | `pid` (필수) | **시스템 구성요소면 거부** |
| `ports.open` | `port` (필수) | 기본 브라우저로 연다 |

### 거부하는 것

| 메서드 | 코드 | 이유 |
|---|---|---|
| `lid.start` · `lid.stop` | `needsHuman` | 관리자 인증이 필요하다 |
| `ports.stop` (시스템) | `forbidden` | 물어볼 사람이 없다 |
| `ports.stop` (이 앱) | `forbidden` | 자기를 끄는 호출이 된다 |

## 오류 코드

| 코드 | 뜻 |
|---|---|
| `badRequest` | JSON 이 아니거나 `method` 가 없다 |
| `unknownMethod` | 없는 메서드 |
| `badParams` | 파라미터가 빠졌거나 형이 틀렸다 |
| `notFound` | 그 pid·포트가 목록에 없다 |
| `forbidden` | 정책으로 막은 것 |
| `needsHuman` | 사람의 인증·확인이 필요한 것 |
| `preconditionFailed` | 조건이 안 맞는다 (사진 없이 커버 시작 등) |
| `internalError` | 그 외 |

## 완료 조건

- 앱이 뜨면 소켓이 `0600` 으로 생기고, 앱이 죽으면 사라진다
- `scripts/mymactools status` 가 네 Tool 의 상태를 JSON 으로 낸다
- `nc -U` 와 python 소켓으로도 같은 결과가 나온다
- 잠자기 방지를 API 로 켜면 **창의 표시도 함께 바뀐다** (같은 상태를 본다)
- 거부 대상 세 가지가 각각 제 코드로 거부된다
- 앱이 안 떠 있으면 클라이언트가 그렇다고 말한다
- `docs/api.md` 에 메서드 표와 붙여 쓸 수 있는 예시가 있다

## 범위에서 빼는 것

- **MCP 서버** — 별도 프로세스가 필요하고, 셸 호출만으로도 에이전트가 쓸 수 있다.
  `docs/api.md` 에 MCP 로 감쌀 때의 예시만 적어둔다
- **원격 접근** — 이 맥 안에서만 쓴다
- **이벤트 구독** — 상태가 바뀔 때 알려주는 것. 지금은 물어보는 쪽만 만든다
